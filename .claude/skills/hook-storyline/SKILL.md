# Hooks and storyline

## 1. Split the material into meaningful segments
From `packed.md`: segments by **complete thought** (not by timer), 20–60 s. For each, record:
the thesis, the emotion, the benefit to the viewer, whether there is visual confirmation (a frame), and a 1–5 score on the axes
hook · completeness · emotion · density of value · payoff.

## 2. Choose a structure
| Goal | Structure |
|---|---|
| Product / object | Result or before/after first → 3 benefits → offer |
| Expert | Counterintuitive thesis → proof → one practical step |
| Object showcase | Strongest view as the first frame → route → next step |
| SaaS | Pain in one phrase → one task in the interface → result and metric → CTA |
| Story / film | Story spine: once upon a time → every day → but one day → because of that → and finally |
| Selling Reels | PAS (problem → agitation → solution) or BAB (before → after → bridge) |

## 3. Timing
- **15 s:** hook 0–2 s → value → CTA.
- **30 s:** hook 3 s / context and stakes 18 s / value 6 s / CTA 3 s.
- **60 s:** hook + 3 mini-loops of 15 s each + CTA at about the 50th second.
- A pattern interrupt every 2–4 s (change of shot, zoom, text, sound).
- Leads come from videos watched past 15 s, so retention matters more than brevity.

## 4. The hook
- It is the same across three channels: **what is said + what is seen + what is written**.
- Types: contradiction · result first · "the mistake everyone makes" · visual shock / before-after ·
  open loop · a number or a stake · direct address of a pain point ("Worried it won't survive the winter?").
- It is written **last**, once the whole story is known. 3–5 variants for the sighting round.
- Cold open: the strongest line can be pulled to the start from any point in the material.
- No clickbait that the video does not deliver on.

## 5. Output: beats.md
```markdown
| # | t | beat | what is said | what is seen (source: asset/scene or gen) | on-screen text |
|---|---|---|---|---|---|
| 1 | 0–2 | hook | "…" | a1b2/s07 → f05 insert | "Built in one day?" |
```
