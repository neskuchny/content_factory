# Manual publish kit

Folder `weeks/<W>/07-kits/<channel>/` + an entry in `07-publications.md` with status `kit_ready`.

## Contents
- Media with clear names: `01_W44-R03_cover.png`, `02_W44-R03.mp4`.
- `post.txt` — text ready to copy (with line breaks suited to the platform).
- A link with UTM, hashtags or a board, if needed.
- When to publish (date and time from the plan).
- **One action** for the human: "Open the VK group → New post → paste post.txt → attach 01, 02 → Publish".
- Checklist: AI label in place · link checked · cover chosen.

## Delivery
A short message listing the week's kits with a link to the folder (Drive or repository).
After the human publishes, they send the link, and the publisher records it in the log.
