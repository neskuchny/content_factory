# Контент-завод — быстрый старт по-русски

Полное описание — в [README.md](README.md) (на английском). Здесь главное, чтобы запустить свой завод.

**Что это.** Контент-завод для коротких видео на Claude Code. Агенты планируют неделю, пишут сценарии,
делают ролики (кодом или через генерацию), проверяют их и готовят адаптации под площадки. Каждый ролик
одобряет человек, публикация по умолчанию ручная. Сервера и приложения нет: всё живёт в файлах и git
вашего репозитория.

## Старт: свой завод за одну сессию

1. **Сделайте свою закрытую копию.** Данные о вашем бизнесе (факты о продукте, планы, метрики) должны
   лежать в вашем репозитории, а не в этом. Два способа:
   - создать пустой приватный репозиторий на GitHub и отправить туда клон этого (обновления потом
     забираются одной командой):
     ```bash
     git clone https://github.com/neskuchny/content_factory.git my-factory
     cd my-factory
     git remote rename origin upstream
     git remote add origin <ссылка на ваш приватный репозиторий>
     git push -u origin main      # или имя вашей ветки
     ```
   - или нажать **Use this template** на странице репозитория и выбрать *Private*.

   Только не форк: форк публичного репозитория тоже публичный. Если работаете на своём компьютере,
   мастер настройки сам выполнит команды git — вам останется создать пустой приватный репозиторий на
   GitHub. В облачной сессии (claude.ai/code) сначала сделайте копию, потом начните сессию уже на ней.
2. **Откройте свою копию в Claude Code** — десктоп, терминал или облачная сессия на claude.ai/code.
3. **Напишите «Настрой меня».** Claude отвечает на том языке, на котором вы пишете.
4. **Ответьте на 10 вопросов одним сообщением:** кто вы и что продаёте, сайт и материалы, кто покупает,
   площадки, какой тон нравится, что нельзя говорить, кто может быть в кадре, кто одобряет ролики,
   бюджет на генерации (0 — нормально). Claude заполнит `clients/<ваше-имя>/` и покажет сводку «что я понял», где у каждого
   факта указан источник. Закрытые файлы (паспорт, база продукта, согласия, права) он запишет только
   после вашего «да».
5. **Первый результат:** короткий ролик кодом за 0 кредитов или план первой недели — на выбор.

Продолжить в следующий раз: «Запусти завод». Если настройку не закончили — «Продолжи настройку».
Добавить ещё один бизнес: «Добавь клиента».

## Ваша копия — ваша
В своей копии вы владелец: меняйте правила, добавляйте свои файлы, задачи, агентов, скиллы и маршруты.
Ограничения прав действуют на агентов-исполнителей и на запуски по расписанию, а не на вас. В этот
(публичный) репозиторий изменения попадают только через pull request: если сделали что-то полезное для
всех — присылайте.

Забрать обновления завода (если копия сделана первым способом):
```bash
git fetch upstream && git merge upstream/main
```

## Что понадобится
- Аккаунт Claude с Claude Code (лучше подписка Max).
- Для роликов кодом: ffmpeg 6.1+, Node.js 22+, Chromium. Проверка машины:
  `python3 scripts/setup/preflight.py` — покажет, чего не хватает и как поставить.
- По желанию: свой аккаунт Higgsfield (ИИ-картинки и видео, платно), Linear (доска задач), Google Drive.
- Ключи и пароли **никогда не пишите в чат и не кладите в репозиторий** — только в настройки коннекторов
  или секреты окружения.

## Чего завод не делает
- Не публикует сам без разрешения: по умолчанию готовит комплект для ручной публикации.
- Не выдумывает факты: цены, сроки, свойства и отзывы — только из ваших материалов, иначе вопрос вам.
- Не выдаёт ИИ-картинку за реальный объект: ИИ-кадры помечаются.
- Не снимает людей без согласия, записанного в `brand/consents.md`.
